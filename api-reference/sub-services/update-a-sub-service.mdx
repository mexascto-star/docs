---
title: "Update a sub-service"
description: "Updates fields on a sub-service. Unset fields are left unchanged. Requires the services.write scope."
openapi: "PATCH /sub-services/{id}"
---

Partial update — send only the fields you want to change.

**Required scope:** `services.write`

**Base URL:** `https://mex-pet-app.vercel.app/api/v1`

## Updatable fields

| Parameter | Type | Description |
| --- | --- | --- |
| `name` | string | Customer-facing name |
| `description` | string | Longer detail |
| `price` | number | New price |
| `duration_minutes` | integer | How long it takes |
| `sort_order` | integer | Position in the list |
| `is_active` | boolean | `false` hides it from booking |
| `pricing_model` | string | `fixed` or `per_unit` |
| `unit_label` | string | Unit name for `per_unit` pricing |

<Warning>
  `service_id` cannot be changed. A sub-service stays under the service it was created beneath — sending `service_id` in the body is ignored. To move it, delete it and create it again under the new service.
</Warning>

## Example — change a price

```bash
curl -X PATCH "https://mex-pet-app.vercel.app/api/v1/sub-services/sub_4c0fcd" \
  -H "Authorization: Bearer mxp_live_your_token_here" \
  -H "Content-Type: application/json" \
  -d '{ "price": 28 }'
```

## Example — retire an option

```bash
curl -X PATCH "https://mex-pet-app.vercel.app/api/v1/sub-services/sub_4c0fcd" \
  -H "Authorization: Bearer mxp_live_your_token_here" \
  -H "Content-Type: application/json" \
  -d '{ "is_active": false }'
```

<Tip>
  Prefer `is_active: false` over deleting. Past bookings store the name and price they were sold at, so retiring an option keeps your catalog tidy without touching history.
</Tip>

## Response `200`

Returns the full updated sub-service.

```json
{
  "id": "sub_4c0fcd",
  "object": "sub_service",
  "service_id": "svc_ff6a7b",
  "name": "Dog Boarding (5 x 5)",
  "description": "Overnight stay in a 5x5 suite.",
  "price": 28,
  "duration_minutes": null,
  "sort_order": 0,
  "is_active": true,
  "pricing_model": "fixed",
  "unit_label": null,
  "created_at": "2026-01-01T00:00:00.000Z"
}
```

## Errors

| Status | Type | When |
| --- | --- | --- |
| `404` | `not_found` | No sub-service with that id in your business |
| `403` | `invalid_request_error` | Token lacks the `services.write` scope |
