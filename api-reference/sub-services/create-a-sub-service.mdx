---
title: "Create a sub-service"
description: "Creates a sub-service (add-on / line item) under a parent service. Requires the services.write scope."
---

Creates a priced item beneath an existing service — a boarding suite size, a grooming package, a transport leg.

**Required scope:** `services.write`

**Base URL:** `https://mex-pet-app.vercel.app/api/v1`

## Body parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | ✅ | What the customer sees, e.g. `Dog Boarding (5 x 5)` |
| `service_id` | string | ✅ | The service this belongs under |
| `description` | string |  | Longer detail. Defaults to `null` |
| `price` | number |  | Defaults to `0` |
| `duration_minutes` | integer |  | How long it takes. Defaults to `null` |
| `sort_order` | integer |  | Position in the list. Defaults to `0` |
| `is_active` | boolean |  | Defaults to `true` |
| `pricing_model` | string |  | `fixed` (default) or `per_unit` |
| `unit_label` | string |  | Names the unit when `pricing_model` is `per_unit` |

<Warning>
  `service_id` must belong to **your** business. A service id from another ranch returns `400 invalid_request_error` — it is not treated as "not found", because the token has no business knowing whether it exists.
</Warning>

## Example

```bash
curl -X POST "https://mex-pet-app.vercel.app/api/v1/sub-services" \
  -H "Authorization: Bearer mxp_live_your_token_here" \
  -H "Content-Type: application/json" \
  -d '{
    "service_id": "svc_ff6a7b",
    "name": "Dog Boarding (5 x 5)",
    "price": 24,
    "pricing_model": "fixed",
    "sort_order": 0
  }'
```

## Response `201`

```json
{
  "id": "sub_4c0fcd",
  "object": "sub_service",
  "service_id": "svc_ff6a7b",
  "name": "Dog Boarding (5 x 5)",
  "description": null,
  "price": 24,
  "duration_minutes": null,
  "sort_order": 0,
  "is_active": true,
  "pricing_model": "fixed",
  "unit_label": null,
  "created_at": "2026-01-01T00:00:00.000Z"
}
```

## Errors

| Status | Type | When |
| --- | --- | --- |
| `400` | `invalid_request_error` | `name` or `service_id` missing |
| `400` | `invalid_request_error` | `service_id` is not a service in your business |
| `403` | `invalid_request_error` | Token lacks the `services.write` scope |
